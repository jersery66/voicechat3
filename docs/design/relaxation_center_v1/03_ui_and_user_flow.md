# Relaxation Center UI 与 User Flow

状态：**FUTURE DESIGN / Phase 2 之后实现**

## Offer

禁止“检测到您当前焦虑，建议放松训练”。自然邀请示例：

> 刚才聊这些挺费神的。如果你愿意，我们可以先休息几分钟，做个放松或者
> 玩点简单的东西，再接着聊。

```text
[放松一下]    [继续聊]
```

拒绝立即回聊天，不产生负面标签、不影响量表；接受后进入 `CENTER`，具体内容
完全由用户选择。

## Center 首页

```text
┌─────────────────────────────────────────┐
│                 放松一下                 │
│        选一个现在比较想做的就可以         │
│  跟着做       看一会儿       玩一会儿     │
│  呼吸/肌肉    森林/海浪      泡泡/找一找  │
│  正念         雨声/星空      拼图/落叶    │
│                 [返回聊天]               │
└─────────────────────────────────────────┘
```

不展示积分、排名、等级、连续签到、宝箱或完成次数。运行中的内容始终有退出
入口，可回到 Center 或继续聊天。所有游戏低刺激、建议 2–5 分钟，不设 Game Over、
失败动画、羞辱文字、竞技、抽奖或奖励循环。

## Return

```text
RUNNING → CENTER → [继续聊天] → RETURNING → 原聊天上下文
```

恢复可以自然承接“好，我们接着刚才说的”，不默认说“恭喜完成训练”或“情绪
一定改善”。Phase 2 只做 shell、分类、content cards、返回和 command bridge，
不实现 Agent recommendation 或游戏。
