# A100 vLLM Safety Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development` or `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the A100 deployment a two-service vLLM runtime while ensuring every transcribed voice turn reaches the deterministic crisis boundary before dialogue generation.

**Architecture:** `ConversationCoordinator` will own the safety decision after a pipeline-provided transcription step, then hand the already-transcribed text back to the legacy pipeline without a second ASR pass. The A100 profile will run only the 72B dialogue and 3B Agent vLLM services; the Guard adapter remains optional code, but is not selected by production configuration.

**Tech Stack:** Python 3.12, pytest, PowerShell, vLLM OpenAI-compatible API.
